📄 Resume RAG Pipeline Demo

1

📖 Upload & Parse

Resume PDF is uploaded to Supabase Storage, then parsed to extract text.

parsePDF(buffer)
→ string (full text)
2

✂️ Chunk

Text is split into overlapping chunks (800 chars, 100 char overlap) for better semantic search.

chunkText(text)
→ string[] (chunks)
3

🧮 Embed

Each chunk is embedded using Gemini API to create dense vectors for similarity search.

embedDocument(chunk)
→ number[] (1536 dims)
4

💾 Store

Chunks and embeddings are stored in Supabase with pgvector for semantic search.

insertChunks()
→ resume_chunks table
5

🔍 Search

Query is embedded and matched against chunk embeddings using cosine similarity.

embedQuery(q)
→ top-k chunks
6

💬 Chat

Top chunks are sent to Claude via LangGraph agent to answer screening questions.

LangGraph ReAct
→ assessment

🏗️ Architecture Flow

Resume PDF
    ↓
[parsePDF] → Full Text (12,000+ chars)
    ↓
[chunkText] → Chunks Array (800 chars, 100 overlap)
    ↓
[embedDocument] × N → Embedding Vectors (1536 dims each)
    ↓
[insertChunks] → Supabase Database
    │
    ├─ resume_chunks table (chunk_index, content, embedding)
    ├─ candidates table (name, role_guess, full_text)
    └─ pgvector HNSW index (fast similarity search)
    ↓
User Query
    ↓
[embedQuery] → Query Vector (1536 dims)
    ↓
[vector similarity search] → Top-3 Chunks
    ↓
[LangGraph Agent] + [Claude] → Screening Assessment
    ↓
[createScreening] → Database Storage

✨ Key Features

🎯 Semantic Search

Chunks are searched by meaning, not keywords. A query about "ERP experience" will match chunks mentioning "enterprise resource planning" even without the exact term.

⚡ Fast Retrieval

Supabase pgvector with HNSW indexing enables sub-millisecond similarity search across thousands of resume chunks.

🤖 LLM-Powered Assessment

Retrieved chunks are sent to Claude via LangGraph for intelligent screening, generating structured assessments with reasoning.

💾 Persistent Storage

All screenings, assessments, and candidate data are stored in Supabase, not just localStorage. Multi-user support ready.

🔄 Job-Scoped Context

Screening agent can be scoped to a specific job description, scoring candidates based on job-specific requirements.

📊 Structured Output

Assessments include scores, reasoning, strengths, and gaps—ready for ranking and comparison dashboards.
